# Test Plan — SauceDemo E-commerce Demo

## 1. Project overview
This test plan outlines a manual functional test of the SauceDemo demo storefront. The exercise is intended to practice test design, execution, defect documentation, and evidence capture.

- **Application:** https://www.saucedemo.com/
- **Test type:** Manual functional testing, negative testing, basic usability observations
- **Status:** Planned; execution not yet completed


## 2. Objectives
- Check whether key user workflows behave as expected.
- Verify login and validation behavior.
- Evaluate product sorting and cart operations.
- Check checkout validation and order completion.
- Record reproducible defects with clear evidence if found.


## 3. Scope
### In scope
- Login and logout
- Inventory/product list
- Product sorting
- Add/remove items from cart
- Cart review
- Checkout information form
- Checkout overview and completion
- Error/validation messages

### Out of scope
- Payment processing with real money
- Backend security testing or penetration testing
- Load/performance testing
- Testing undocumented internal services


## 4. Test approach
1. Review the application's available demo credentials and instructions.
2. Execute each test case using the documented steps.
3. Record actual results and set status to Pass, Fail, Blocked, or Not Run.
4. For failures, capture a screenshot and create a bug report.
5. Re-test fixes only if a fix is available; record regression observations.

## 6. Entry criteria
- Demo site is reachable.
- Tester can access the app and any publicly documented test account.
- Test cases and reporting templates are available.


## 7. Exit criteria
- All in-scope test cases have an execution status.
- Failed/blocked tests are explained.
- Observed defects are documented with steps and evidence.
- A concise summary of results is written.


## 8. Risks and limitations
- Demo site behavior or availability may change.
- Results apply only to the environment and date recorded.
- This is a portfolio practice exercise, not a production certification or security audit.
